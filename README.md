A comprehensive Data Analytics project analyzing e-commerce sales performance, customer trends, and product profitability using Power BI.

📊 Project Overview
This project focuses on transforming raw e-commerce data into actionable business insights. The interactive dashboard helps stakeholders track key metrics, identify top-performing regions, and understand customer purchasing patterns.

🛠️ Tools & Technologies Used
Data Visualization: Power BI Desktop

Data Transformation: Power Query (ETL)

Data Modeling: Star Schema Design

Calculations: DAX (Data Analysis Expressions)

🔑 Key Insights & Features
Sales Performance: Tracked total revenue, profit margins, and order volume over time.

Regional Analysis: Highlighted high-revenue locations and shipping mode preferences.

Product Profitability: Identified top-selling product categories and sub-categories.

Interactive Filters: Enabled drill-downs by date ranges, regions, and customer segments.
